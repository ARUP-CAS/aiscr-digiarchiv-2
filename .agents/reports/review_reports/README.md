# Review reports

Per-task and consolidated reports from the repository's codebase-review workflow. The active task set, ordering, scopes, and output paths are owned by [`../../config/review_config.toml`](../../config/review_config.toml) rather than duplicated as a separate table here.

Reports are time-scoped evidence: filenames and task identifiers come from the configuration used to produce them, and their conclusions should be compared with the current repository state before reuse. New evidence follows [`aiscr-review-codebase`](../../skills/aiscr-review-codebase/SKILL.md).

When a workflow renders findings or backlog views, use [`../../scripts/codebase_review.py`](../../scripts/codebase_review.py) rather than editing generated copies independently of their authoritative sources.
